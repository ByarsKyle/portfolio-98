# Portfolio '98

A cozy bedroom, rendered in real time in the browser, with a beige CRT on the
desk that boots into a working Windows 98.

**There are no asset files in this repository.** No `.glb`, no `.fbx`, no
textures, no images, no audio. Every plank of the floor, every fold in the
duvet, every wrinkle on the dog, every pixel of the operating system and every
sound — including the dial-up handshake — is generated by code when the page
loads, in about four seconds.

---

## Getting around

| | |
|---|---|
| `W A S D` | walk |
| `Mouse` | look |
| `Shift` | run |
| `E` | interact — sit at the computer, pet the dog, toggle the lamp, lie down |
| `Esc` | stand up / release the cursor |

Walk up to the monitor and press **E**. The camera dollies to 25 cm from the
tube until the screen fills the frame — it is not an overlay, you are simply
close to the mesh. Everything you then click is the same curved, scanlined,
glowing surface you were looking at from across the room.

Inside the machine: a BIOS POST, the Windows 98 boot splash, a desktop with a
real window manager, Internet Explorer (which needs a dial-up connection
first — open **Dial-Up Networking** and hit Connect), Minesweeper, Snake,
Notepad, Paint, Media Player, an MS-DOS prompt, a Recycle Bin with some
regrets in it, and a screensaver if you leave it alone for a while.

Try `Ctrl+Alt+Delete`. Try typing `HELP` at the DOS prompt.

## How it works

### The forge — `src/forge/`

The asset pipeline. Nothing is loaded; everything is authored as a function.

- **`noise.js`** — seeded value/gradient noise, fBm, ridged multifractal and
  Worley cells. Deterministic, so every build looks identical.
- **`texture.js`** — the PBR baker. A surface is written once as
  `shade(u, v, out) → [height, r, g, b, roughness, metalness]`, and the baker
  turns that into a full map set: albedo, roughness, metalness, a
  tangent-space normal derived by running a Sobel filter over the height
  field, and a cavity AO map from the difference between the height and its
  own low-pass.
- **`materials.js`** — fifteen shading functions: oak floorboards that know
  about plank seams, grain rings and the worn path through the middle of the
  room; painted plaster with orange-peel roll texture; open-pore walnut;
  quilted duvet cover; cut-pile rug; aged beige computer plastic that has
  yellowed in patches. Baked lazily and cached.
- **`geo.js`** — geometry constructors. Rounded boxes built by pushing a
  subdivided cube out to a rounded-cube SDF (real bevels catch real
  highlights), lathes, extrusions, tapered tubes, organic blobs, catenary
  cables, and a Verlet **cloth solver**.

### The cloth

The duvet, the top sheet, the curtains, the rug and the hoodie on the end of
the bed are not modelled. They are simulated. A grid of points is dropped from
above and relaxed for a few hundred iterations against the mattress and a
couple of invisible spheres, so the folds fall where physics puts them.

### The monitor — `src/assets/desktop.js`

A 17" tube whose glass genuinely bulges outward, wrapped in a shader that does
barrel distortion, an aperture-grille RGB mask, scanlines with a slow roll,
per-channel convergence error, phosphor glow, corner vignette and a power-on
ramp that collapses the image into a line when you shut down.

The screen samples its own average colour every few frames and feeds it to a
`RectAreaLight`, so the monitor actually lights the room, and the colour of
that light changes with what is on screen.

### The operating system — `src/os/`

About two thousand lines drawing Windows 98 onto a 640×480 canvas: bevels,
gradients, title bars, menus, dialogs, scrollbars and every icon, all hand
drawn with 2D canvas primitives. That canvas is the CRT's texture. There is a
real window manager underneath — drag, focus, z-order, minimise, maximise —
and each app is a small module in `src/os/apps/`.

The site inside Internet Explorer lives in one object at the top of
`src/os/apps/browser.js`. If you fork this to make it your own portfolio,
that's the only thing you need to edit.

### The sound — `src/core/audio.js`

Synthesised with WebAudio at runtime. Room tone, the flyback whine of the CRT
(which gets louder as you approach it), footsteps, UI chimes, a MIDI-flavoured
sequencer for the Media Player, and a dial-up handshake that goes through DTMF
dialling, ring tone, the V.8 answer tone, the probing chirps, the scrambled
data bursts and the final carrier hiss, in roughly the right order and roughly
the right timings. It is annoying on purpose.

## Running it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # → dist/
```

There is also a screenshot harness used while building this, which drives the
scene in headless Chrome and grabs a set of views:

```bash
node tools/shoot.mjs [outdir]
```

## Notes

Best on a desktop with a keyboard and mouse. It wants WebGL2 and roughly a
2015-or-later GPU; the post chain falls back to an 8-bit framebuffer on
drivers without `OES_texture_half_float_linear`.

Everything on the little website inside the computer is placeholder copy —
swap it for your own.
